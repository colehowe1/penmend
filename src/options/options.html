It already checks spelling and grammar in every text box as you type, free and on this computer. Click an underline to fix it, or the round badge in the corner of a text box to see everything.

Claude Off

Claude catches what the local checker misses (wrong words, awkward or unclear sentences) and rewrites text when you ask. It runs on your own Anthropic API key, billed by Anthropic for what you use.

Create one at console.anthropic.com → API keys. It's stored only in this Chrome profile (never synced) and web pages can't read it.

Privacy

      
The local checker (Harper, open source) runs entirely in Chrome on this computer. Nothing you type leaves your computer unless Claude is set up; then only the paragraphs being checked, and text you ask to rewrite, go to Anthropic's API under your key. Penmend has no server of its own and collects nothing.

      
Built with Harper (Apache-2.0, by Automattic) and the Anthropic SDK. Their licenses are in the extension's licenses folder.
